## Player avatars

`avatars.h` — 16x16 overworld sprites, generated by `tools/gen_avatars.py`
from [pret/pokered](https://github.com/pret/pokered) (`gfx/sprites/*.png`), the
Pokémon Red/Blue disassembly. Only the first frame of each sheet is used, recoloured
onto a four-entry palette. Since v3.38 that is 21 sprites: the 19 playable avatars
(the player, the rival and every Gen 1 trainer class) plus MOM, drawn on the
blackout screen, and OAK, not yet used. Adding them did not change the licensing
position below; it put more of the same art in the repo, at the owner's request.

**These are Nintendo / Game Freak / Creatures artwork and are _not_ licensed for
redistribution**, unlike the PMD sprites (CC BY-NC) or the badges (CC BY 3.0).
The disassembly publishes them for research and preservation; that is not a
licence grant, and this project has no rights over them.

They are here because the project owner asked for the real sprites, and this
entry exists so that the choice is documented rather than quietly made. If the
repo is published, the clean approach is the same one already recommended for
the PMD sprites above: **ship `tools/gen_avatars.py` and not `avatars.h`**, so
each user fetches the art themselves — the script needs only `curl` and takes a
second to run.

## Game Corner and Surfing Pikachu art

`gamecorner_art.h` — generated by `tools/gen_gamecorner.py` (v3.53) from three
pret disassemblies: Red's six slot-reel symbols ([pret/pokered](https://github.com/pret/pokered)
`gfx/slots/red_slots_2.png`), Crystal's reel symbols and the four card-flip
pictures ([pret/pokecrystal](https://github.com/pret/pokecrystal) `gfx/slots/`,
`gfx/card_flip/`), and Pikachu on its surfboard ([pret/pokeyellow](https://github.com/pret/pokeyellow)
`gfx/surfing_pikachu/`). The reel strips and payout tables in `gamecorner.cpp`
are the games' own data, read from the same disassemblies.

**Exactly the same position as the avatars above**: Nintendo / Game Freak /
Creatures artwork, not licensed for redistribution, here at the owner's request
(2026-10-22). If the repo is published, **ship `tools/gen_gamecorner.py` and not
`gamecorner_art.h`**; it needs only `curl` and Pillow.

## Gym badge artwork

Two sources, because no single one covers every region.

### Kanto through Unova

**https://github.com/SteGriff/pokemon-badges** -- SVG recreations of the first 40
league badges, Kanto through Unova, traced from Bulbapedia. Stephen Griffiths,
2011, **CC BY 3.0** (attribution required, commercial use permitted).

`svg/Kanto.svg` holds the eight badges, and `tools/gen_badges.py` renders it
with `rsvg-convert`, isolates each and packs them into `badges.h` at 32x32.

**CC BY requires this attribution to travel with anything built from it** --
firmware binaries included, not just the source.

### Kalos

**MarillTachiquin** -- "Simple Kalos Region Badges (Pokemon X Y)", vectors drawn
in Inkscape from in-game references.

  https://www.deviantart.com/marilltachiquin/art/Simple-Kalos-Region-Badges-Pokemon-X-Y-410369360

That set exists because the SteGriff collection stops at Unova; there is no
Kalos sheet in it, and no other openly licensed one was found.

**THE ARTIST'S OWN TERMS**, quoted from the deviation's description so the
condition travels with the file rather than being paraphrased away:

> "Vector made with Inkscape. Please credit me if you're going to use them
> somewhere. Badges originally made by Nintendo, Game Freak, The Pokemon Co.,
> etc. etc."

So: **credit is the condition, and this section is that credit.** It has to ship
with anything built from `badges.h`, exactly as the CC BY attribution above
does. The page also carries a CC BY-NC-ND 3.0 tag; this project is
non-commercial and attributes, and the artist's written request to be credited
when using the badges is the permission being relied on here.

The sheet is committed as `tools/kalos_badges.png` so `gen_badges.py` stays
reproducible -- the DeviantArt image URL is signed and expires, so a build that
re-fetched it would break. `gen_badges.py` isolates the eight badges from that
raster by connected component (the sheet is a 4x2 grid whose rows overlap, so
the column splitter used for the SVG sheets cannot cut it) and packs them at
32x32 like the rest.

**If this project is ever published in a form that would trouble either artist,
the honest fix is the one already recommended for the player avatars: ship
`tools/gen_badges.py` and let each user fetch the art themselves.**
