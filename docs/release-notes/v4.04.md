## TamaPoke v4.04

**The gauntlet opens in the Battle Zone.** Pick a set of rules and face challengers one after another until you lose. Each challenger is a little tougher than the last, and every win pays Battle Points (BP).

- **Rules**: a type every creature must have, a level cap (creatures above it fight at the cap), which forms may enter (basic, middle, final, or no legendaries), and a team size from 1 to 6. The challengers follow the same rules.
- **Daily challenge**: new rules every day, the same on every board. The first daily run each day that beats at least one challenger earns double BP for the rest of that run. **Custom** rules are yours to set and pay the normal BP.
- **Your run is saved between battles**, so you can stop and come back days later with the PP you had left. Only one run at a time; QUIT asks twice. Turning the board off in the middle of a battle counts as losing it.
- Your best streak and today's best daily streak are recorded.

**SKETCH fix:** a SKETCH that fails (nothing to copy yet) no longer uses up its only PP. It says the move failed, and SMEARGLE can try again next turn.

Nothing to do: your save is untouched.
