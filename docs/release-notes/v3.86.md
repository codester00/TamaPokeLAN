## v3.86 -- Backups hold everything

**A save backup now includes everything you have, right up to the moment it is
taken.** The game saves in batches, and a backup used to copy only what had
already been saved -- so a TM bought, or a medal earned, just before backing up
could be missing from the backup file. The installer backs up right before it
installs, which is exactly when that mattered.

Nothing to do: update as usual. Your save carries over unchanged. If you keep a
backup file from an older version, it still restores; taking a fresh one after
updating is a good idea.
