Small changes under the hood. Your save carries over; back up first and leave
"Erase device" unchecked, as always.

- **The Memory game waits for you.** Tapping a berry while it is still showing
  the sequence used to do nothing. Now the showing pauses and starts over a
  moment after your last tap, so a stray tap never makes you miss the sequence.
- **Hard mode's team-size limit is decided in one place.** Picking your team and
  starting the fight now ask the same question, so they can never disagree.

Nothing else changes in normal play. LAN battles still need both boards on
v3.58 or later; trading works with v3.55 and later.
