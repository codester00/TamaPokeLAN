## TamaPoke v3.97

**Every Ditto knows TRANSFORM now.** v3.96 taught it only to a Ditto you were raising, so one waiting in your party or in Bill's PC still knew nothing until you raised it. Now every Ditto you already have learns it the first time the board starts on this version. Nothing to do.

**Hoenn's hard League is winnable again.** With the leader-by-leader tuning, even a team built for each matchup lost most Hoenn League runs. Glacia, Drake and Wallace are a little softer on hard, and a well-built team now wins the run almost every time.
