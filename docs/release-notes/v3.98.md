## TamaPoke v3.98

**A transformed Ditto looks the part.** Ditto copied its opponent's moves, stats and typing, but kept standing there as a Ditto. Now its picture changes to the creature it copied the moment the battle says "transformed into". Its name still reads DITTO, as in the main games. Nothing to do.

**Better clues for a rare freeze.** One board sometimes froze its picture for about a second during Rock Smash. This version adds more detail to the board's diagnostic log, so the cause can be pinned down. Play as usual.
