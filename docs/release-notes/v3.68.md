## v3.68 -- backups that arrive whole

**The installer's backup could fail on a board with Pokemon in Bill's PC.** The
page read "No backup taken: backup is ... bytes but declares ..." and offered
to install anyway. The board was sending the backup faster than the connection
could carry it, and a few bytes went missing on the way. The page noticed and
refused the damaged copy, which is the right call, but it left you without a
backup.

Now the board waits for the connection instead of skipping ahead, and the page
reads the backup again by itself if a copy arrives damaged.

**If you are updating from v3.66 or v3.67:** click **Backup, then install**. The
page retries on its own, so the backup should work even before this update is
on your board. If it still says "No backup taken", try once more. Installing
never touches your save either way, as long as you do not choose "Erase
device".
