Clearer battles. Your save carries over; back up first and leave "Erase device"
unchecked, as always.

**Both boards need this version for LAN battles**, because the two boards now
share more about each turn. Trading works with v3.60 and later.

- **Health falls with the message that explains it.** The bars used to drop the
  moment you picked a move, before any of the turn's text had been read. Now each
  hit drains the bar while its own line is on screen, in the order things
  happened, so you can tell which attack did what.
- **Poison and burns say so.** Damage at the end of a turn has its own line --
  "X is hurt by poison!" -- and its own drop in health, instead of being folded
  silently into the last attack.
- **Both players see the same battle in LAN.** The second board used to be told
  only which moves were used and who fainted; it now reads every line the host
  does -- critical hits, super effective, misses, stat changes, poison -- with the
  health bars moving at the same moments.
- **A CAUGHT mark on wild creatures.** A small ball on a wild creature's name
  plate means you already own one of its species.
