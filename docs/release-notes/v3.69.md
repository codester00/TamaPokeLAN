## v3.69 -- Smeargle learns Sketch

**Smeargle could not learn a single move.** In the real games its only move is
Sketch, and this game did not have it, so a Smeargle reached level 35 knowing
nothing and could only Struggle in a fight.

**Sketch is here now.** Smeargle learns Sketch at level 1 and again at 11, 21,
31 and every ten levels after, like any other move it learns by levelling up:
it goes into an empty slot by itself, or, if all four slots are full, you are
asked which move to forget. It does not learn it again while it still knows
Sketch. In a battle, using Sketch copies the move your opponent used last, with
full PP, and Smeargle keeps that move for good, so you build its moveset by
choosing what to fight. Sketch fails if the opponent has not moved yet, or if
Smeargle already knows that move. It works in LAN battles too.

**Wild Smeargle now know four random moves**, and keep them if you catch one.
Raise one and it is offered Sketch at its next Sketch level.

**If you already have a Smeargle:** update, and one that knows no moves learns
Sketch straight away.

Both boards need this update to battle each other over LAN.
